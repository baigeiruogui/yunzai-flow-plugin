# 云崽 Flow 插件 — 总交付报告

> 对象：`云崽可视化工作流插件_开发文档_v1.0.md`（26 章）。本报告汇总 25 轮迭代的最终交付物、证据与缺口。

## 一、这是什么

一套**可运行的云崽可视化工作流插件 MVP**：ComfyUI 风格深色节点画布 + 完整执行引擎（分支/循环/合流/错误域/去重/幂等/副作用账本）+ NapCat 178 项能力全映射与结构化表单 + 存储/发布/导入导出/数据源/子图/代码节点/直连 OneBot。

- 后端：Node.js ESM，**零外部依赖**
- 前端：原生 JS 无限画布，**无构建**
- 启动：`node src/server.mjs` → http://&lt;host&gt;:5088/
- 测试：`npm test`（**45/45 通过**） · 验收：`npm run verify` → `docs/ACCEPTANCE.md`

## 五、缺口（都需要真实外部环境，非本地可伪造）

1. **实机验证**（把 `实机 0` 抬起）：需要一个可连的真实 **NapCat**（`config.napcat.httpUrl/wsUrl/accessToken` 或 UI「传输」里填），代码已就绪、本地 OneBot 协议端点已跑通。
2. **真实 TRSS-Yunzai 宿主挂载**：需要云崽实例，`index.js` 入口与 HostAdapter 已就绪。
3. 行为契约（retcode/回执语义）可继续对 mock 扩写；结构化表单中源码提取项为启发式解析，复杂嵌套类型降级（已在覆盖报告标注）。

> 依据文档 §24.2：覆盖率按 `映射 / 表单 / 结构契约 / 可执行契约 / 行为 / 实机` 分轴给出，绝不以"节点数量"或"一个原始调用入口"冒充全覆盖。
