# 云崽 Flow 插件 — 实现对照报告

> 对照对象：`云崽可视化工作流插件_开发文档_v1.0.md`（v1.0，1674 行 / 26 章）
> 本报告说明：哪些章节已落地、哪些是部分/路线图，以及证据位置。数据来自 `docs/ACCEPTANCE.md`（脚本生成）与 `npm test`。

## 一句话

一套**可运行的云崽可视化工作流插件 MVP**：深色节点画布 + 25 家族/199 操作（NapCat 178 项全映射，65 项结构化表单）+ 真实执行语义（分支/循环/去重/幂等/副作用账本/加密/Redis/SQLite/SSE/子图/数据源/直连 OneBot）。**33 个引擎与契约测试全绿**。

## 怎么跑

```bash
cd plugins/yunzai-flow-plugin
node src/server.mjs            # 打开 http://<host>:5088/
npm test                       # 33 个测试
npm run verify                 # 生成 docs/ACCEPTANCE.md
node scripts/mock-onebot.mjs   # 本地 OneBot 协议服务器（联调直连，端口 5701）
```

技术栈：Node.js ESM 后端（零外部依赖）+ 原生前端（无构建）。文件结构近似文档 §21。

## 关键证据

- `docs/ACCEPTANCE.md`：33/33 测试；25 家族/199 操作；NapCat 178 映射 / 65 结构化 / 113 通用 / 2 契约 / 0 实机；事件 38。
- 直连真链路：`scripts/mock-onebot.mjs` + `POST /transport`，`wf_hello` real 运行 → 本地 OneBot 收到真实 `send_msg`，回执 `message_id`、`simulated:false`。
- 测试文件 `test/engine.test.mjs`：33 条，覆盖 §24.1 的 RUN-02、GRAPH-01/04、CRYPTO-01/02、SECRET-01、REDIS-02/03、VERSION、HTTP-01、§7.2 循环、§16 代码隔离、§17 子图锁、§18.4 导入导出、§15 数据源、§13.6 传输 retcode、§8.1 宿主探测、§20 配对。

## 与真实环境的唯一缺口

1. **真实 TRSS-Yunzai 宿主挂载**：HostAdapter 已就绪、能探测 `global.Bot/global.redis`，但需要在真云崽进程里加载（`index.js` 入口已留）。
2. **真实 NapCat 联调**：传输层（HTTP/WS、retcode/echo、token）已完成并有 mock 契约测试；填入真实 `config.napcat.httpUrl/wsUrl/accessToken` 即切真机。
3. **178 全结构化表单**：当前 65 结构化 + 113 通用；铺满需继续补 overlay 与逐项实测。

这三项都需要真实环境/持续投入，非本地可凭空完成；其余核心链路均已本地可运行、可复现、有测试。
